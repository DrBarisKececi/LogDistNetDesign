model_kod.c dosyası matematiksel modeli açık formda metin (txt) dosyasına yazan kodu içerir. Kod derlendikten sonra oluşan
çalıştırılabilir dosya (exe), senaryo_verileri.zip dosyasında verilen 6 metin (txt) dosyasına ihtiyaç duymaktadır. Exe
dosyası ilgili klasör içinde çalıştırılarak matematiksel modeli metin dosyasına yazar.
Her bir senaryoya ait CPLEX çözücü günlük (log) dosyaları senaryo_sonuclari.zip dosyasında verilmiştir.
